# Screenshots

Place your macOS screenshots in this folder with the following filenames so they automatically render in the main [`README.md`](../README.md):

- `about-this-mac.png` — Screenshot of **About This Mac** (showing macOS Sequoia, CPU, RAM, and GTX 1660 Super).
- `graphics.png` — Screenshot of **System Information -> Graphics/Displays** (showing Metal acceleration).
- `usb-map.png` — Screenshot of your USB port mapping / Hackintool / USBToolBox.
- `desktop.png` — Full desktop or system overview screenshot.
